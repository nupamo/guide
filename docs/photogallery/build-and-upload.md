# 빌드 전에 확인하기

월드를 업로드하기 전에 갤러리와 사진 설정을 확인해 주세요.

## Build Photo Max Size

`PhotoGallery`의 Advanced 영역에 `Build Photo Max Size` 옵션이 있습니다.

- `None`: 원본 사진 크기를 그대로 사용합니다.
- `1024` / `2048`: 빌드 시 사진을 긴 변 기준으로 1024 또는 2048 안에 들어가게 리사이즈합니다.

사진이 아주 많거나 원본 이미지가 매우 크다면 `1024` 또는 `2048`을 추천합니다. 월드 용량과 메모리 사용량을 줄이는 데 도움이 됩니다.

선명도가 가장 중요하고 사진 수가 많지 않다면 `None`을 사용해도 됩니다.

## 사진 텍스처 설정

이 에셋은 사진을 추가할 때 텍스처의 `Non-Power of 2` 설정을 `None`으로 조정합니다.

액자를 단독으로 사용할 때는 수동설정이 필요합니다.

## Udon 동기화 기능은 포함되어 있지 않습니다

이 에셋은 월드 제작자가 미리 배치한 사진을 보여주는 용도입니다.

월드 안에서 유저가 직접 사진을 바꾸거나, 네트워크로 사진을 동기화하는 기능은 포함되어 있지 않습니다.
