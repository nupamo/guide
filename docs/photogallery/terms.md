# 이용 약관

### 사용
- VRChat 월드, 게임 제작 및 상업적 이용이 가능합니다.

### 금지
- 툴 자체를 제3자가 사용할 수 있도록 재배포하는 것은 금지합니다. 
- 판매용 에셋에 포함시키고 싶은 경우는 [AutoResize PhotoFrame Lite](https://booth.pm/ko/items/1740420)를 사용해주세요.

### 면책
- 본 툴을 사용하여 발생하는 모든 법적 문제 및 손해에 대해 제작자는 책임을 지지 않습니다.
