# AutoResize PhotoFrame

`vrc-autoresize-photoframe`는 **VRChat용 동적 텍스처 사진 프레임 셰이더**예요.  
입력 사진의 실제 해상도 비율을 읽어서 프레임 형태가 자연스럽게 맞춰지도록 설계돼 있어요.

## 프로젝트 개요

이 프로젝트는 VRChat 월드나 아바타에서 사진을 보여줄 때,
이미지 비율이 제각각이라 프레임이 찌그러져 보이거나 어색하게 잘리는 문제를 줄이기 위해 만들어졌어요.

핵심은 단순한 UI 이미지 컴포넌트가 아니라:

- **Unity/VRChat용 셰이더**이고
- **텍스처 해상도 비율을 직접 읽을 수 있으며**
- **오브젝트 스케일과 함께 프레임 외형을 자동 보정**한다는 점이에요.

## 포함 파일

프로젝트에는 다음 파일이 포함되어 있어요.

- `autoresize photoframe.shader`
- `PhotoFrame.prefab`
- `PhotoFrame(Panorama).prefab`
- `Photo Material.mat`
- `Photo Material(Panorama).mat`

즉, 셰이더만 있는 게 아니라 바로 가져다 쓸 수 있는 프리팹/머티리얼 세트까지 포함된 구성이에요.

## 어떻게 동작하나

셰이더는 두 가지 방식으로 비율을 결정해요.

### 1. 수동 비율 지정

아래 프로퍼티로 원하는 비율을 직접 넣을 수 있어요.

- `_RatioWidth`
- `_RatioHeight`

예:

- 16:9 → `16`, `9`
- 4:3 → `4`, `3`
- 1:1 → `1`, `1`

### 2. 텍스처에서 자동 비율 읽기

`_RatioAuto`를 켜면 텍스처 해상도에서 가로/세로 비율을 읽어 자동으로 반영해요.

이게 이 프로젝트의 핵심 포인트예요.  
즉, 업로드되는 사진이 가로형인지 세로형인지에 따라 프레임 메쉬 표현이 자동으로 달라져요.

## 주요 셰이더 프로퍼티

실제 셰이더 기준으로 중요한 항목은 이거예요.

### 기본 표시

- `_MainTex`: 표시할 메인 텍스처
- `_MainColor`: 메인 색상
- `_Lit`: Albedo ↔ Emission 전환값

`_Lit`을 조절해서 조명 영향을 받는 쪽으로 둘지, 발광처럼 보이게 둘지 선택할 수 있어요.

### 비율 관련

- `_RatioWidth`
- `_RatioHeight`
- `_RatioAuto`

보통:

- 고정 포스터/정해진 출력물 → 수동 비율
- 사용자 업로드 사진/동적 텍스처 → 자동 비율

이렇게 나누면 좋아요.

### 정렬 관련

- `_AlignV`: `Top / Center / Bottom`
- `_AlignH`: `Right / Center / Left`

자동 리사이즈가 일어날 때 프레임 기준점을 어디에 둘지 결정해요.

예를 들면:

- 세로 확장 시 위쪽 기준으로 붙이고 싶으면 `Top`
- 좌우 균형이 중요하면 `Center`
- 특정 벽면/배치 기준이 있으면 `Left` 또는 `Right`

### 프레임/여백 스타일

- `_Frame`: 프레임 두께 강도
- `_Margin`: 내부 여백 강도
- `_FrameColor`
- `_FrameTex`
- `_MarginColor`
- `_MarginTex`

즉, 이 셰이더는 단순히 비율만 맞추는 게 아니라:

- 바깥 프레임
- 안쪽 마진
- 텍스처/컬러 스타일

까지 같이 제어할 수 있어요.

## 실제 동작 포인트

셰이더 내부에서는 대략 이런 흐름으로 동작해요.

1. 오브젝트의 월드 스케일(`scaleX`, `scaleY`)을 읽어요.
2. 텍스처 비율 또는 수동 비율 값을 가져와요.
3. 가로형/세로형인지 계산해요.
4. 버텍스를 이동시켜 프레임 형태를 자동 보정해요.
5. 정렬 옵션에 따라 pivot 느낌으로 위치를 보정해요.
6. surface 단계에서 메인 이미지/마진/프레임을 합성해요.

즉, **단순 UV 크롭이 아니라 버텍스 단계에서 프레임 외형 자체를 조정**하는 방식이에요.

## 사용 방법

### 기본 사용

1. Unity 프로젝트에 파일을 임포트해요.
2. `PhotoFrame.prefab` 또는 `PhotoFrame(Panorama).prefab`을 씬에 배치해요.
3. 사진용 텍스처를 `_MainTex`에 연결해요.
4. 필요하면 `_RatioAuto`를 켜요.
5. 큐브/오브젝트 스케일을 조정해서 원하는 전체 크기를 맞춰요.

## Panorama 버전

`PhotoFrame(Panorama).prefab`과 `Photo Material(Panorama).mat`는 README 설명상
`VRC_Panorama` 환경에서 쓰기 좋게 준비된 버전이에요.

파노라마 표시용 월드에서 사진 프레임을 자연스럽게 맞추고 싶을 때 이쪽을 우선 써보면 좋아요.

## 추천 세팅

### 동적 사용자 사진 프레임

- `_RatioAuto`: On
- `_AlignH / _AlignV`: Center
- `_Frame`: 중간
- `_Margin`: 약간

사용자가 어떤 비율의 사진을 넣어도 무난하게 대응하기 좋아요.

### 고정 비율 포스터 프레임

- `_RatioAuto`: Off
- `_RatioWidth / _RatioHeight`: 명시
- `_AlignH / _AlignV`: 원하는 배치 기준에 맞춤

출력 비율이 항상 일정한 경우에는 이쪽이 더 예측 가능해요.

### 발광형 사진 프레임

- `_Lit`: 1에 가깝게

어두운 공간이나 사이버/클럽 계열 월드에서 사진이 더 또렷하게 보여요.

## 주의할 점

- 자동 비율은 **입력 텍스처 해상도**에 의존해요.
- 오브젝트 스케일도 결과에 영향을 줘요.
- 정렬 옵션에 따라 프레임이 늘어나는 방향 체감이 달라져요.
- 월드/아바타 환경에 따라 실제 보이는 결과는 꼭 테스트해보는 게 좋아요.

## 언제 쓰면 좋은가

이 프로젝트는 특히 이런 경우에 잘 맞아요.

- VRChat 월드에 사진 업로드/표시 기능이 있을 때
- 사진 비율이 매번 달라 수동 조정이 번거로울 때
- 파노라마 환경에서 프레임 표현을 깔끔하게 맞추고 싶을 때
- 프레임/마진 스타일까지 한 셰이더에서 같이 다루고 싶을 때

## 요약

`vrc-autoresize-photoframe`는 **텍스처 비율 기반 자동 프레임 보정 셰이더**예요.

특징을 한 줄로 정리하면:

> 동적 사진 비율을 읽어 VRChat용 사진 프레임 메쉬와 표시를 자연스럽게 보정해주는 셰이더/프리팹 패키지
