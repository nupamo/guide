# シェーダー設定

このドキュメントでは、`AutoResize PhotoFrame Pro`および`AutoResize PhotoFrame Lite`マテリアルに表示される設定項目について説明します。

## Surface

Proマテリアルでのみ表示されます。マテリアルのレンダリング方式を決定します。

- `Opaque`: 不透明レンダリングです。ほとんどの場合に推奨されます。
- `Transparent`: 透明レンダリングです。ガラスの感じや半透明の表現を強くしたい場合に使用します。

## Image

写真自体に関する設定です。

### Main Texture

表示する写真のテクスチャです。

`PhotoGallery`を使用する場合、各写真が`Photos`リストから自動的に挿入されます。単一の額縁を直接配置する場合は、ここに写真を入れることができます。

### Main Color

写真に乗算される色です。

デフォルトは白です。写真を暗くしたり、特定の色で少し染めたい場合に調整します。

### Image Unlit

写真が照明の影響をどれだけ受けにくくするかを決定します。

- `0`: ワールドの照明の影響を大きく受けます。
- `1`: 照明の影響が少なく、写真がそれ自体で明るく見えます。

VRChatワールドで写真が暗すぎる場合は、値を上げてみてください。

Liteでは、同じ役割の項目が`Image Unlit`または`Lit`として表示される場合があります。

## Frame

Proマテリアルでのみ表示されます。

左側のチェックボックスをオフにすると、フレーム効果が無効になります。

### Frame Size

額縁フレームの太さです。

値が大きいほど、写真の周囲のフレームが太くなります。

### Frame Texture

フレームに使用するテクスチャです。

木目、金属、紙の質感などの画像を入れることができます。

### Frame Normal Map

フレームの表面の凹凸を表現するノーマルマップです。

木目や立体感をより強調したい場合に使用します。

### Frame Color

フレームの色です。

`Frame Texture`がある場合、テクスチャの色にこの色が乗算されます。

### Frame Bump Scale

フレームのノーマルマップの強度です。

値が大きいほど、表面の凹凸が強く見えます。

### Frame Bevel

フレームの端の疑似ベベル（面取り）効果の強度です。

額縁の縁が平坦に見える場合、値を上げると立体感が生まれます。

### Bevel Highlight

フレームのベベルの明るい部分の強度です。

### Bevel Shadow

フレームのベベルの暗い部分の強度です。

### Inner Shadow

写真と余白の内側に生じる影の強度です。

写真が額縁の内側に少し入り込んでいるような印象を与えます。

### Raised Mesh Depth

フレームが前に突き出て見える深さです。

デフォルトの`PhotoFrame`プレハブの突出メッシュと一緒に使用すると効果がよく見えます。

### Frame Unlit

フレームが照明の影響をどれだけ受けにくくするかを決定します。

- `0`: ワールドの照明の影響を受けます。
- `1`: それ自体で明るく見えます。

## Margin

写真の周囲の余白に関する設定です。

ProとLiteの両方で使用できます。

### Margin Size

写真の周囲の余白のサイズです。

値が大きいほど、写真とフレームの間のスペースが広くなります。

### Margin Texture

余白に使用するテクスチャです。

紙の質感やパターンを入れる場合に使用します。

### Margin Color

余白の色です。

白であれば一般的な写真マットの感じを出せますし、透明度を下げると背景が透けて見える表現も可能です。

### Margin Shadow

余白の内側の影の強度です。

写真の端やフレームの内側に奥行きを加えます。

### Margin Shadow Size

余白の影の幅です。

値が大きいほど、影が広く広がります。

### Margin Unlit

余白が照明の影響をどれだけ受けにくくするかを決定します。

## Glass

Proマテリアルでのみ表示されます。

左側のチェックボックスをオフにすると、ガラス効果が無効になります。

### Glass Strength

ガラス効果の全体の強度です。

値が高いほど、ガラスの色合いや反射光がよく見えます。

### Glass Tint

ガラスの色です。

少し青みやグレーを入れると、写真の上に薄いガラスが乗っている感じを出せます。

### Glass Glare

ガラスの反射光の強度です。

値が高いほど、斜めのハイライトや端のきらめきが強くなります。

### Glass Glare Size

反射光の幅です。

値が大きいほど、ハイライトが広く広がります。

### Glass Smoothness

ガラスの滑らかさです。

値が高いほど、スペキュラー反射がより滑らかに見えます。

## Alignment

写真が表示領域内でどこに配置されるかを決定します。

写真の比率と額縁の比率が異なる場合、空きスペースが生じることがあります。この時、配置オプションが適用されます。

### Vertical align

縦の配置です。

- `Top`: 上揃え
- `Center`: 中央揃え
- `Bottom`: 下揃え

### Horizontal align

横の配置です。

- `Left`: 左揃え
- `Center`: 中央揃え
- `Right`: 右揃え

## Ratio

写真の比率をどのように決定するかを設定します。

### Aspect ratio from texture

写真テクスチャの実際のアスペクト比を自動的に使用します。

ほとんどの場合、オンにしておくことをお勧めします。

### Set ratio

`Aspect ratio from texture`をオフにした場合に、手動で使用する比率です。

例：

- 16:9 横向きの写真: `16, 9`
- 正方形: `1, 1`
- 9:16 縦向きの写真: `9, 16`

特定のサイズのポスターフレームのように、常に同じ比率で見せたい場合に使用します。
