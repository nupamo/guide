# ビルド前の確認

ワールドをアップロードする前に、ギャラリーと写真の設定を確認してください。

## Build Photo Max Size

`PhotoGallery`のAdvanced領域に`Build Photo Max Size`オプションがあります。

- `None`: 元の写真サイズをそのまま使用します。
- `1024` / `2048`: ビルド時に写真の長辺が1024または2048に収まるようにリサイズします。

写真が非常に多い場合や、元の画像が非常に大きい場合は、`1024`または`2048`をお勧めします。これは、ワールドの容量とメモリ使用量を減らすのに役立ちます。

鮮明さが最も重要で、写真の数が多くない場合は、`None`を使用してもかまいません。

## 写真テクスチャ設定

このアセットは、写真を追加する際、テクスチャの`Non-Power of 2`設定を自動的に`None`に調整します。

額縁を単独で使用する場合は、手動設定が必要です。

## Udon同期機能は含まれていません

このアセットは、ワールド制作者が事前に配置した写真を表示するためのものです。

ワールド内でユーザーが直接写真を変更したり、ネットワーク経由で写真を同期する機能は含まれていません。
