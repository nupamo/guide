# ギャラリーの配置調整

`PhotoGallery`コンポーネントは、複数の写真を自動的に配置します。写真を追加したりオプションを変更すると、Sceneの額縁が更新されます。

## Photos

ギャラリーに表示する写真テクスチャのリストです。

リストの順序通りに額縁が生成されます。順序を変更すると、ギャラリー内の写真の順序も変わります。

## Gap

額縁間の間隔です。

- X: 横の間隔
- Y: 縦の間隔

写真が重なる場合は値を大きくし、もっと密接に配置したい場合は値を小さくします。

## Slot Size

各写真が占める基本配置サイズです。

`Frame Scale`は実際の額縁プレハブのサイズで、`Slot Size`はギャラリーの配置間隔を計算する際の基準サイズです。額縁の実際のサイズと行間隔を別々に調整したい場合に便利です。

## Row Count

1行に配置する基準数です。

例えば、写真が10枚で`Row Count`が2の場合、2行のギャラリーとして配置されます。

## Layout Direction

写真を埋める方向です。

- `Horizontal`: 横方向に先に埋めます。
- `Vertical`: 縦方向に先に埋めます。

壁全体に広く配置したい場合は`Horizontal`、縦長の展示形式が必要な場合は`Vertical`を試してください。

## Frame Position / Rotation / Scale

各スロット内に入る`PhotoFrame`の位置、回転、スケールです。

ほとんどの場合、デフォルト値で十分です。額縁が壁に埋もれすぎたり浮いて見える場合は、`Frame Position`のZ値を調整してみてください。

## Additional Child Prefab

各写真スロットに一緒に追加するプレハブです。

例えば、写真ごとに小さなラベル、装飾オブジェクト、照明などを一緒に配置したい場合に使用できます。

追加のプレハブを使用すると、`Additional Position`、`Additional Rotation`、`Additional Scale`で位置とサイズを調整できます。

## Resetボタン

現在の設定に基づいて、ギャラリーの子オブジェクトを再作成します。

プレハブを変更した際や、配置が予期せず崩れた場合に使用してください。

## Snap Children To Wallボタン

各額縁を壁のコライダーにスナップさせます。

使用条件は以下の通りです。

- 壁オブジェクトにコライダー（Collider）が必要です。
- `PhotoGallery`オブジェクトが、スナップさせたい壁の方を向いている必要があります。
- 額縁の前後方向がおかしい場合は、`PhotoGallery`オブジェクトを180度回転させてから再度試してください。
