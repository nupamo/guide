# 糸車オルゴール (Spinning Wheel Music Box)

糸車オルゴールは、VRChatワールドに置ける手回しの紙楽譜オルゴールです。

紙の楽譜が糸車のような車輪にぐるりと掛かり、回りながら演奏します。紙にあいた穴が櫛歯に届くたびに音が鳴ります。
ハンドルを速く回すほど曲も速くなり、手を離すと本物のオルゴールのようにゆっくり止まります。

## できること

- ハンドルを自分で回して演奏（手動）、または自動でくり返し再生（自動）
- MMLの楽譜を貼ってすぐに演奏（6トラック・6000文字まで、マビノギのMMLにも対応）
- YouTubeリンクを貼り、曲を聴きながら紙に穴をあけて楽譜を作る（PC専用）
- 作った曲をワールドデータに保存して、次に来たときも聴ける（1人10曲まで）
- 同じインスタンスにいる人たちが保存した曲を、ひとつのリストでいっしょに聴く
- 4種類の音色（オルゴール、マリンバ、ピアノ、クラヴィコード）の切り替え

インスタンスの全員が、同じ曲を同じタイミングで聴きます。
