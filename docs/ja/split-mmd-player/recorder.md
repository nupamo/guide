# Recorder

Split MMD Recorderの機能説明です。

- `Player`: 録画するPlayerを選択します。
- `Output Mode`: `Normal`、`SBS`、`VR180`
- `Output`: 連番画像と動画が保存されるディレクトリです。
- `Resolution`: 動画の解像度プリセットです。5.7Kは標準ですが、YouTubeではサポートされていません。
- `Quality`: 品質
- `Output Size`: 動画の解像度
- `FPS`: 動画のフレームレート
- `FFmpeg`: 動画のエンコードに使用するffmpegを選択します。選択しない場合はPNGのみ抽出されます。
