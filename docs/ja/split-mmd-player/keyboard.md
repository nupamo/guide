# キーボード操作

Split MMD Playerのキーボード操作方法です。マウスでクリックしたViewに対して適用されます。

![image](/keyboard.png)

- W,S: 拡大/縮小
- A,D: 左右移動
- Space,C: 上下移動
- Q,E: 左右回転
- X,Z: 上下回転
- R: リセット

---

- Tab: カメラタイプ変更
- 0~9: ターゲットDancer変更
- F1~F8: Player変更
