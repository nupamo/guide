# Recorder

Split MMD Recorder의 기능 설명입니다.

- `Player`: 녹화할 Player를 선택합니다.
- `Output Mode`: `Normal`, `SBS`, `VR180`
- `Output`: 시퀸스 및 영상이 저장될 디렉토리입니다.
- `Resolution`: 영상 해상도 프리셋입니다. 5.7K는 표준이지만 유튜브에서 지원하지 않습니다.
- `Quality`: 품질
- `Output Size`: 영상 해상도
- `FPS`: 영상 주사율
- `FFmpeg`: 영상 인코딩에 사용할 [FFmpeg](https://ffmpeg.org/download.html)를 선택합니다. 선택하지 않으면 png만 추출됩니다.
