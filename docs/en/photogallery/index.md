AutoResize PhotoGallery is a Unity asset designed for placing multiple photos, illustrations, and posters in VRChat worlds all at once.

When you add a photo texture, the frame automatically adjusts to display it at the correct aspect ratio. You don't have to calculate mesh sizes manually for each photo or worry about spacing between them.

Since it does not use Udon at all and scripts are removed during the build phase, it can be used for avatar creation or non-VRChat projects as well.

## What it can do

- Automatically adjusts frame size to match photo proportions
- Places multiple photos at once in a gallery format
- Adjusts spacing between frames, row count, and layout direction
- Automatically snaps frames to wall colliders
