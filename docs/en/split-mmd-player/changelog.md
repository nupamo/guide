# Changelog

## Studio v1.5.0 (2026-07-26)

- feat: Added runtime playback controls.
- feat: Added playback keyboard shortcuts.

## Studio v1.4.0 (2026-07-14)

- feat: Added Tools/nupamo/Split MMD Recorder.

## Studio v1.3.0 (2026-07-05)

- feat: Added 3D Mode.
- feat: Added keyboard controls.
- feat: Added Summer Preset.

## Studio v1.2.0 (2026-06-20)

- feat: Scene Builder now uses Scene assets instead of Stage Prefabs.
- feat: Added Day and Night presets.
- fix: Fixed a bug where creating a new Scene could erase the old Scene data.
- fix: Added a confirmation step before overwriting an existing Scene.
- fix: Mirror floor is hidden in the lower angle.
- fix: Runtime UI Hide option is now saved.

## Studio v1.1.0 (2026-06-17)

- feat: Added support for Gesture Manager and SPS.
- feat: Added Post Process support and a default profile.
- feat: Added support for Unity `AnimationClip` motions.
- feat: Player remembers parameter changes made in Play Mode.
- feat: Multiple Player components can share the same Dancer and Audio components.
- feat: Added Dancer Transform Offset.
- feat: Motion can be changed during Play Mode.
- feat: Changed the default stage to Mirror floor and Sakura petal.
- feat: Changed the default motion and song.
- fix: Unused Dancers are now hidden.

## v1.0.1 (2026-06-11)

- fix: Fixed a VMD Camera interpolation issue.

## v1.0.0 (2026-06-03)

- Initial release.
