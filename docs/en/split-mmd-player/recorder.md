# Recorder

Split MMD Recorder provides recording features.

- `Player`: Select the Player to record.
- `Output Mode`: `Normal`, `SBS`, `VR180`
- `Output`: Directory where the image sequence and video will be saved.
- `Resolution`: Video resolution preset. 5.7K is standard, but is not supported by YouTube.
- `Quality`: Quality
- `Output Size`: Video resolution
- `FPS`: Video frame rate
- `FFmpeg`: Select ffmpeg to use for video encoding. If not selected, only PNG files are extracted.
