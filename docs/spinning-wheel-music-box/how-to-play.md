# 오르골 사용법

오르골 가까이 가면 상자 위에 조작 화면이 나타나고, 멀어지면 사라집니다.
화면은 사람마다 따로 보이고, 글자는 VRChat 언어 설정(영어, 일본어, 한국어, 중국어)을 따릅니다.

## 곡 목록

| 표시 | 뜻 |
| --- | --- |
| 줄을 누르기 | 그 곡을 재생합니다. 재생 중인 줄을 다시 누르면 멈춥니다. |
| `×` | 내가 저장한 곡입니다. 누르면 내 목록에서 지울지 묻습니다. |
| 플레이어 이름 | 다른 사람이 저장한 곡입니다. 누르면 내 목록에도 저장할지 묻습니다. |
| 표시 없음 | 월드에 들어 있는 기본 곡입니다. |

새로 만든 곡은 목록 맨 위에 최신순으로 나오고, 기본 곡은 그 아래에 있습니다.

## 손잡이 돌리기

목록 아래의 `수동` / `자동`으로 재생 방식을 고릅니다.

- **수동**: 손잡이를 잡고 돌리면 그 속도로 종이가 흐르며 연주됩니다. 방향은 상관없습니다. 너무 빨리 돌려도 원래 빠르기의 1.5배까지만 빨라집니다.
- **자동**: 손잡이를 돌리지 않아도 곡을 반복 재생합니다. 자동 재생 중에 손잡이를 잡으면 수동으로 바뀝니다.

손잡이를 돌리는 사람의 속도가 모두에게 전달되므로, 다른 사람이 돌려도 같은 소리가 들립니다.

## 악보 추가하기

목록 아래의 `+ 악보 추가`를 누릅니다.

### MML 붙여 넣기

1. `MML` 탭을 고릅니다.
2. 마비노기 MML 악보를 붙여 넣습니다. 여러 트랙은 `,`로 나눈 형식 그대로 넣으면 됩니다. (6트랙, 6,000자까지)
3. 필요하면 아래쪽 `곡 이름 (선택)` 칸에 이름을 적습니다. 비워 둬도 됩니다.
4. `추가하고 재생`을 누르면 바로 목록 맨 위에 들어가고 재생됩니다.

### YouTube 링크로 만들기 (PC 전용)

1. `유튜브 링크` 탭을 고르고 링크를 붙여 넣습니다.
2. `● 녹음`을 누르면 곡을 들으면서 종이에 구멍을 뚫어 나갑니다.
3. 영상이 끝나거나 `■ 정지하고 저장`을 누르면 그때까지 뚫은 부분이 악보로 정리되어 목록에 들어갑니다.

- 오르골 소리는 원곡보다 약 17초 늦게 나옵니다. 구멍이 뚫린 종이가 빗살까지 이동하는 시간입니다.
- 원곡은 링크를 넣은 사람에게만 아주 작게 들립니다. 다른 사람에게는 오르골 소리만 들립니다.
- 피아노나 오르골 커버 영상이 가장 잘 됩니다. 노래가 크게 들어간 곡은 결과가 좋지 않고, 반주가 많은 곡은 "그럴듯한 편곡" 수준이 됩니다.
- Quest에서는 녹음할 수 없습니다. 다른 사람이 녹음하는 모습과 소리는 Quest에서도 보이고 들립니다.

## 저장

- 만든 곡은 내 VRChat 데이터에 저장됩니다. 나중에 같은 월드에 다시 와도 목록에 남아 있습니다.
- 한 사람당 **10곡**까지 저장할 수 있습니다. 다 차면 새 곡을 추가하기 전에 `×`로 기존 곡을 지워 달라는 안내가 나옵니다.
- 목록에는 지금 인스턴스에 있는 모든 사람이 저장한 곡이 합쳐서 나옵니다. 같은 곡은 한 줄로 나옵니다.
- 저장한 사람이 인스턴스를 나가면 그 사람만 가진 곡은 목록에서 빠집니다. 마음에 드는 곡은 이름을 눌러 내 목록에 저장해 두세요.
- `×`는 내 저장에서만 지웁니다. 다른 사람도 저장한 곡이면 그 사람 이름으로 목록에 남습니다.

## 악기, 언어, 볼륨

화면 오른쪽 위 톱니바퀴를 누릅니다. 화면 글자는 고른 언어로 나오며, 아래는 한국어 기준입니다.

- **음색**: 오르골, 마림바, 피아노, 클라비코드 중에서 고릅니다. 모두에게 바로 바뀌고, 재생 중에도 바꿀 수 있습니다.
- **언어**, **음량**: 내 화면과 내 소리에만 적용됩니다.
