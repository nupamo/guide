AutoResize PhotoGallery 是一款 Unity 资源，可在 VRChat 世界中一次性布置多张照片、插画和海报。

放入照片纹理后，相框会自动按照片的宽高比调整显示。无需逐张计算网格尺寸，也无需手动安排照片间距。

该资源完全不使用 Udon，脚本会在构建过程中移除，因此也可用于虚拟形象制作或 VRChat 以外的项目。

## 功能

- 按照片宽高比自动调整相框尺寸
- 一次性将多张照片排列成画廊
- 调整相框间距、行数和排列方向
- 根据墙面的 Collider 自动吸附相框
