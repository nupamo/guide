AutoResize PhotoGallery 是一款 Unity 資源，可在 VRChat 世界中一次佈置多張照片、插畫和海報。

放入照片貼圖後，相框會自動依照照片的長寬比調整顯示。無需逐張計算網格尺寸，也無需手動安排照片間距。

此資源完全不使用 Udon，指令碼會在建置過程中移除，因此也可用於虛擬形象製作或 VRChat 以外的專案。

## 功能

- 依照片長寬比自動調整相框尺寸
- 一次將多張照片排列成畫廊
- 調整相框間距、列數和排列方向
- 根據牆面的 Collider 自動吸附相框
