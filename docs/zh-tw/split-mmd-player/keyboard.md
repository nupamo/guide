# 鍵盤操作

本頁介紹 Split MMD Player 的鍵盤操作。操作會套用至用滑鼠點擊的 View。

![鍵盤操作示意圖](/keyboard.png)

## 播放

- `J`、`L`（`←`、`→`）：向後或向前跳轉 5 秒
- `K`：暫停或繼續播放
- `,`、`.`：向後或向前移動 1 個影格
- `Shift + ,`、`Shift + .`：以 0.25 倍為單位調整播放速度

## 攝影機

- `W`、`S`：放大或縮小
- `A`、`D`：左右移動
- `Space`、`C`：上下移動
- `Q`、`E`：左右旋轉
- `X`、`Z`：上下旋轉
- `R`：重設
- `Tab`：切換攝影機類型
- `0`～`9`：切換目標舞者
- `F1`～`F8`：切換播放器
