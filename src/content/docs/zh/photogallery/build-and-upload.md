# 构建前检查

上传世界前，请检查画廊和照片设置。

## Build Photo Max Size

`PhotoGallery` 的 Advanced 区域中有 `Build Photo Max Size` 选项。

- `None`：保留照片的原始尺寸。
- `1024` / `2048`：构建时调整照片大小，使长边不超过 1024 或 2048。

如果照片很多或原始图片很大，建议使用 `1024` 或 `2048`。这有助于减少世界文件大小和内存占用。

如果清晰度最重要且照片数量不多，也可以使用 `None`。

## 照片纹理设置

此资源会在添加照片时，将纹理的 `Non-Power of 2` 设置为 `None`。

单独使用相框时，需要手动设置。

## 不包含 Udon 同步功能

此资源用于展示由世界制作者预先布置的照片。

不包含让用户在世界中直接更换照片或通过网络同步照片的功能。
