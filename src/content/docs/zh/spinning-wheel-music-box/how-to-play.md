# 八音盒的使用方法

走近八音盒，箱子上方会出现操作画面；走远后画面会消失。
每个人看到的画面是分开的，文字会跟随 VRChat 的语言设置（英语、日语、韩语、中文）。

## 曲目列表

| 显示 | 含义 |
| --- | --- |
| 点击一行 | 播放这首曲子。再次点击正在播放的那一行会停止。 |
| `×` | 你保存的曲子。点击后会询问是否从你的列表中删除。 |
| 玩家名字 | 别人保存的曲子。点击后会询问是否也保存到你的列表。 |
| 无标记 | 世界自带的曲子。 |

新做的曲子按时间从新到旧排在列表最上面，自带曲子在它们下面。

## 转动摇柄

在列表下方的 `手动` / `自动` 中选择播放方式。

- **手动**：抓住摇柄转动，纸乐谱会按你的速度移动并演奏。方向不限。无论转得多快，最多只会达到原速的 1.5 倍。
- **自动**：不用转动也会循环播放。自动播放时抓住摇柄会切换为手动。

转动的人的速度会同步给所有人，所以别人转动时你也会听到同样的声音。

## 添加乐谱

点击列表下方的 `+ 添加乐谱`。

### 粘贴 MML

1. 选择 `MML` 标签。
2. 粘贴 MML 乐谱，多轨用 `,` 分隔。洛奇 MML（`MML@...;`）也可以直接使用。（最多 6 轨、6000 字符）
3. 如有需要，在下方 `曲名（可选）` 栏中填写名字，也可以留空。
4. 点击 `添加并播放`，曲子会加到列表最上面并开始播放。

### 用 YouTube 链接制作（仅限 PC）

1. 选择 `YouTube 链接` 标签并粘贴链接。
2. 点击 `● 录制`，八音盒会一边听歌一边在纸上打孔。
3. 视频结束或点击 `■ 停止并保存` 后，目前打好的孔会整理成乐谱并加入列表。

- 八音盒的声音会比原曲晚约 17 秒。这是打好孔的纸乐谱移动到音梳所需的时间。
- 原曲只有粘贴链接的人能听到，而且音量很小。其他人只会听到八音盒的声音。
- 钢琴或八音盒翻奏视频效果最好。人声很大的歌曲效果不好，伴奏多的歌曲会变成"大致像样的编曲"。
- Quest 无法录制。不过别人录制时的画面和声音，在 Quest 上也能看到、听到。

## 保存

- 做好的曲子会保存到世界数据中。以后再来同一个世界，它们仍在列表里。
- 每人最多保存 **10 首**。存满后，添加新曲前会提示你先用 `×` 删除旧曲。
- 列表会合并显示当前实例中所有人保存的曲子。相同的曲子只显示一行。
- 保存者离开实例后，只有他保存的曲子会从列表中消失。喜欢的曲子可以点名字保存到自己的列表。
- `×` 只会从你自己的保存中删除。如果别人也保存了这首曲子，它会以对方的名字留在列表里。

## 音色、语言、音量

点击画面右上角的齿轮。

- **音色**：从八音盒、马林巴、钢琴、手碟中选择。会立即对所有人生效，播放中也能切换。
- **语言**、**音量**：只影响你自己的画面和声音。
