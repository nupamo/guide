# 键盘操作

本页介绍 Split MMD Player 的键盘操作。操作会应用到用鼠标点击的 View。

![键盘操作示意图](/keyboard.png)

## 播放

- `J`、`L`（`←`、`→`）：向后或向前跳转 5 秒
- `K`：暂停或继续播放
- `,`、`.`：向后或向前移动 1 帧
- `Shift + ,`、`Shift + .`：以 0.25 倍为单位调整播放速度

## 摄像机

- `W`、`S`：放大或缩小
- `A`、`D`：左右移动
- `Space`、`C`：上下移动
- `Q`、`E`：左右旋转
- `X`、`Z`：上下旋转
- `R`：重置
- `Tab`：切换摄像机类型
- `0`～`9`：切换目标舞者
- `F1`～`F8`：切换播放器
