# オルゴールの使い方

オルゴールに近づくと箱の上に操作画面が現れ、離れると消えます。
画面は人ごとに別々に表示され、文字はVRChatの言語設定（英語・日本語・韓国語・中国語）に合わせて変わります。

## 曲リスト

| 表示 | 意味 |
| --- | --- |
| 行を押す | その曲を再生します。再生中の行をもう一度押すと止まります。 |
| `×` | 自分が保存した曲です。押すと、自分のリストから削除するか確認します。 |
| プレイヤー名 | ほかの人が保存した曲です。押すと、自分のリストにも保存するか確認します。 |
| 表示なし | ワールドに入っている最初からの曲です。 |

新しく作った曲はリストのいちばん上に新しい順で並び、最初からの曲はその下にあります。

## ハンドルを回す

リストの下の `手動` / `自動` で再生方法を選びます。

- **手動**：ハンドルをつかんで回すと、その速さで紙が流れて演奏します。回す向きはどちらでもかまいません。どんなに速く回しても、元の速さの1.5倍までです。
- **自動**：ハンドルを回さなくても曲をくり返し再生します。自動再生中にハンドルをつかむと手動に切り替わります。

回している人の速さが全員に伝わるので、ほかの人が回しても同じ音が聴こえます。

## 楽譜を追加する

リストの下の `+ 楽譜を追加` を押します。

### MMLを貼る

1. `MML` タブを選びます。
2. MMLの楽譜を貼ります。複数トラックは `,` で区切ります。マビノギのMML（`MML@...;`）もそのまま使えます。（6トラック・6000文字まで）
3. 必要なら、下の `曲名（任意）` 欄に名前を入れます。空のままでもかまいません。
4. `追加して再生` を押すと、リストのいちばん上に入ってすぐに再生されます。

### YouTubeリンクから作る（PC専用）

1. `YouTubeリンク` タブを選び、リンクを貼ります。
2. `● 録音` を押すと、曲を聴きながら紙に穴をあけていきます。
3. 動画が終わるか `■ 停止して保存` を押すと、そこまでにあけた穴が楽譜にまとめられてリストに入ります。

- オルゴールの音は原曲より約17秒遅れて鳴ります。穴をあけた紙が櫛歯まで進む時間です。
- 原曲はリンクを貼った人にだけ、ごく小さく聴こえます。ほかの人にはオルゴールの音だけが聴こえます。
- ピアノやオルゴールのカバー動画がいちばんうまくいきます。ボーカルが大きい曲は向いておらず、伴奏の多い曲は「それっぽい編曲」くらいになります。
- Questでは録音できません。ほかの人が録音している様子と音は、Questでも見たり聴いたりできます。

## 保存

- 作った曲はワールドデータに保存されます。あとで同じワールドに来ても、リストに残っています。
- 1人 **10曲** まで保存できます。いっぱいになると、新しい曲を追加する前に `×` で古い曲を消すよう案内が出ます。
- リストには、いまインスタンスにいる全員が保存した曲がまとめて表示されます。同じ曲は1行になります。
- 保存した人がインスタンスを出ると、その人だけが持っていた曲はリストから消えます。気に入った曲は名前を押して自分のリストに保存しておきましょう。
- `×` は自分の保存から消すだけです。ほかの人も保存している曲は、その人の名前でリストに残ります。

## 音色・言語・音量

画面右上の歯車を押します。

- **音色**：オルゴール、マリンバ、ピアノ、クラヴィコードから選びます。全員にすぐ反映され、再生中でも切り替えられます。
- **言語**・**音量**：自分の画面と自分の音にだけ反映されます。
