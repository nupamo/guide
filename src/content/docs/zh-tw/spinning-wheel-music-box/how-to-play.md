# 音樂盒的使用方法

走近音樂盒，箱子上方會出現操作畫面；走遠後畫面會消失。
每個人看到的畫面是分開的，文字會跟隨 VRChat 的語言設定（英文、日文、韓文、中文）。中文會以簡體顯示。

## 曲目清單

| 顯示 | 意思 |
| --- | --- |
| 點一下某一行 | 播放這首曲子。再點一次正在播放的那一行會停止。 |
| `×` | 你儲存的曲子。點一下會詢問是否從你的清單中刪除。 |
| 玩家名稱 | 別人儲存的曲子。點一下會詢問是否也儲存到你的清單。 |
| 沒有標示 | 世界內建的曲子。 |

新做的曲子依時間由新到舊排在清單最上面，內建曲子在它們下面。

## 轉動搖柄

在清單下方的 `手动`（手動）/ `自动`（自動）中選擇播放方式。

- **手動**：抓住搖柄轉動，紙樂譜會照你的速度移動並演奏。方向不限。不管轉得多快，最多只會到原速的 1.5 倍。
- **自動**：不用轉動也會循環播放。自動播放時抓住搖柄會切換成手動。

轉動的人的速度會同步給所有人，所以別人轉動時你也會聽到同樣的聲音。

## 新增樂譜

點一下清單下方的 `+ 添加乐谱`（新增樂譜）。

### 貼上 MML

1. 選擇 `MML` 分頁。
2. 貼上 MML 樂譜，多軌用 `,` 分隔。瑪奇 MML（`MML@...;`）也可以直接使用。（最多 6 軌、6000 字元）
3. 需要的話，在下方 `曲名（可选）` 欄位填寫名稱，也可以留空。
4. 點一下 `添加并播放`（新增並播放），曲子會加到清單最上面並開始播放。

### 用 YouTube 連結製作（僅限 PC）

1. 選擇 `YouTube 链接` 分頁並貼上連結。
2. 點一下 `● 录制`（錄製），音樂盒會一邊聽歌一邊在紙上打孔。
3. 影片結束或點一下 `■ 停止并保存`（停止並儲存）後，目前打好的孔會整理成樂譜並加入清單。

- 音樂盒的聲音會比原曲晚約 17 秒。這是打好孔的紙樂譜移動到音梳所需的時間。
- 原曲只有貼上連結的人聽得到，而且音量很小。其他人只會聽到音樂盒的聲音。
- 鋼琴或音樂盒翻奏影片效果最好。人聲很大的歌曲效果不好，伴奏多的歌曲會變成「大致像樣的編曲」。
- Quest 無法錄製。不過別人錄製時的畫面和聲音，在 Quest 上也看得到、聽得到。

## 儲存

- 做好的曲子會儲存到世界資料中。之後再來同一個世界，它們仍在清單裡。
- 每人最多儲存 **10 首**。存滿後，新增新曲前會提示你先用 `×` 刪除舊曲。
- 清單會合併顯示目前實例中所有人儲存的曲子。相同的曲子只會顯示一行。
- 儲存者離開實例後，只有他儲存的曲子會從清單中消失。喜歡的曲子可以點名稱儲存到自己的清單。
- `×` 只會從你自己的儲存中刪除。如果別人也儲存了這首曲子，它會以對方的名稱留在清單裡。

## 音色、語言、音量

點一下畫面右上角的齒輪。

- **音色**：從音樂盒、馬林巴、鋼琴、手碟中選擇。會立即對所有人生效，播放中也能切換。
- **語言**、**音量**：只影響你自己的畫面和聲音。
