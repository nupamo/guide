# 建置前檢查

上傳世界前，請檢查畫廊和照片設定。

## Build Photo Max Size

`PhotoGallery` 的 Advanced 區域中有 `Build Photo Max Size` 選項。

- `None`：保留照片的原始尺寸。
- `1024` / `2048`：建置時調整照片大小，使長邊不超過 1024 或 2048。

如果照片很多或原始圖片很大，建議使用 `1024` 或 `2048`。這有助於減少世界檔案大小和記憶體用量。

如果清晰度最重要且照片數量不多，也可以使用 `None`。

## 照片貼圖設定

此資源會在加入照片時，將貼圖的 `Non-Power of 2` 設定為 `None`。

單獨使用相框時，需要手動設定。

## 不包含 Udon 同步功能

此資源用於展示由世界製作者預先佈置的照片。

不包含讓使用者在世界中直接更換照片或透過網路同步照片的功能。
