# 키보드 조작

Split MMD Player의 키보드 조작 사용법입니다. 마우스 클릭한 View에 대해 적용됩니다.

![image](/keyboard.png)

## 재생

- `J`,`L`(`←`,`→`): 5초씩 앞뒤 이동
- `K`: 일시정지, 재생
- `,`,`.`: 1프레임씩 앞뒤 이동
- `Shift + ,`, `Shift + .`: 0.25x씩 배속 변경

## 카메라

- `W`,`S`: 확대 축소
- `A`,`D`: 좌우 이동
- `Space`,C`: 상하 이동
- `Q`,`E`: 좌우 회전
- `X`,`Z`: 상하 회전
- `R`: 리셋
- `Tab`: 카메라 타입 변경
- `0`~`9`: 타겟 댄서 변경
- `F1`~`F8`: 플레이어 변경
