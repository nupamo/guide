# 셰이더 설정

이 문서는 `AutoResize PhotoFrame Pro`와 `AutoResize PhotoFrame Lite` 머티리얼에서 보이는 설정 항목을 설명합니다.

## Surface

Pro 머티리얼에서만 보입니다. 머티리얼의 렌더링 방식을 정합니다.

- `Opaque`: 불투명 렌더링입니다. 대부분의 경우 권장합니다.
- `Transparent`: 투명 렌더링입니다. 유리 느낌이나 반투명 표현을 강하게 쓰고 싶을 때 사용합니다.

## Image

사진 자체에 대한 설정입니다.

### Main Texture

표시할 사진 텍스처입니다.

`PhotoGallery`를 사용할 때는 각 사진이 `Photos` 리스트에서 자동으로 들어갑니다. 단일 액자만 직접 배치하는 경우에는 이곳에 사진을 넣어도 됩니다.

### Main Color

사진에 곱해지는 색상입니다.

기본값은 흰색입니다. 사진을 어둡게 하거나 특정 색으로 살짝 물들이고 싶을 때 조정합니다.

### Image Unlit

사진이 조명의 영향을 얼마나 덜 받을지 정합니다.

- `0`: 월드 조명의 영향을 많이 받습니다.
- `1`: 조명 영향이 적고 사진이 자체적으로 밝게 보입니다.

VRChat 월드에서 사진이 너무 어둡게 보이면 값을 올려 보세요.

Lite에서는 같은 역할의 항목이 `Image Unlit` 또는 `Lit`으로 표시될 수 있습니다.

## Frame

Pro 머티리얼에서만 보입니다.

왼쪽 체크박스를 끄면 프레임 효과가 비활성화됩니다.

### Frame Size

액자 프레임의 두께입니다.

값이 클수록 사진 주변 프레임이 두꺼워집니다.

### Frame Texture

프레임에 사용할 텍스처입니다.

나무결, 금속, 종이 질감 같은 이미지를 넣을 수 있습니다.

### Frame Normal Map

프레임의 표면 굴곡을 표현하는 노멀맵입니다.

나무결이나 입체감을 더 강하게 보이게 할 때 사용합니다.

### Frame Color

프레임 색상입니다.

`Frame Texture`가 있을 경우 텍스처 색상에 이 색이 곱해집니다.

### Frame Bump Scale

프레임 노멀맵의 강도입니다.

값이 클수록 표면 굴곡이 강하게 보입니다.

### Frame Bevel

프레임 모서리의 가짜 bevel 효과 강도입니다.

액자 테두리가 납작해 보일 때 값을 올리면 입체감이 생깁니다.

### Bevel Highlight

프레임 bevel의 밝은 부분 강도입니다.

### Bevel Shadow

프레임 bevel의 어두운 부분 강도입니다.

### Inner Shadow

사진과 여백 안쪽에 생기는 그림자 강도입니다.

사진이 액자 안으로 살짝 들어간 듯한 느낌을 줍니다.

### Raised Mesh Depth

프레임이 앞으로 튀어나와 보이는 깊이입니다.

기본 `PhotoFrame` 프리팹의 돌출 메쉬와 함께 사용할 때 효과가 잘 보입니다.

### Frame Unlit

프레임이 조명의 영향을 얼마나 덜 받을지 정합니다.

- `0`: 월드 조명의 영향을 받습니다.
- `1`: 자체적으로 밝게 보입니다.

## Margin

사진 주변 여백에 대한 설정입니다.

Pro와 Lite 모두 사용할 수 있습니다.

### Margin Size

사진 주변 여백의 크기입니다.

값이 클수록 사진과 프레임 사이의 공간이 넓어집니다.

### Margin Texture

여백에 사용할 텍스처입니다.

종이 질감이나 패턴을 넣을 때 사용합니다.

### Margin Color

여백 색상입니다.

흰색이면 일반적인 사진 매트 느낌을 만들 수 있고, 투명도를 낮추면 배경이 비쳐 보이는 표현도 가능합니다.

### Margin Shadow

여백 안쪽 그림자의 강도입니다.

사진 가장자리나 프레임 안쪽에 깊이감을 더합니다.

### Margin Shadow Size

여백 그림자의 폭입니다.

값이 클수록 그림자가 넓게 퍼집니다.

### Margin Unlit

여백이 조명의 영향을 얼마나 덜 받을지 정합니다.

## Glass

Pro 머티리얼에서만 보입니다.

왼쪽 체크박스를 끄면 유리 효과가 비활성화됩니다.

### Glass Strength

유리 효과의 전체 강도입니다.

값이 높을수록 유리 틴트와 반사광이 더 잘 보입니다.

### Glass Tint

유리 색상입니다.

살짝 푸른색이나 회색을 주면 사진 위에 얇은 유리가 얹힌 느낌을 만들 수 있습니다.

### Glass Glare

유리 반사광의 강도입니다.

값이 높을수록 대각선 하이라이트와 가장자리 반짝임이 강해집니다.

### Glass Glare Size

반사광의 폭입니다.

값이 클수록 하이라이트가 넓게 퍼집니다.

### Glass Smoothness

유리의 매끄러움입니다.

값이 높을수록 specular 반사가 더 매끄럽게 보입니다.

## Alignment

사진이 표시 영역 안에서 어디에 붙을지 정합니다.

사진 비율과 액자 비율이 다르면 남는 공간이 생길 수 있습니다. 이때 정렬 옵션이 적용됩니다.

### Vertical align

세로 정렬입니다.

- `Top`: 위쪽 정렬
- `Center`: 가운데 정렬
- `Bottom`: 아래쪽 정렬

### Horizontal align

가로 정렬입니다.

- `Left`: 왼쪽 정렬
- `Center`: 가운데 정렬
- `Right`: 오른쪽 정렬

## Ratio

사진 비율을 어떻게 정할지 설정합니다.

### Aspect ratio from texture

사진 텍스처의 실제 가로세로 비율을 자동으로 사용합니다.

대부분의 경우 켜 두는 것을 권장합니다.

### Auto Resize Image Only

Auto Resize가 이미지 영역에만 적용되도록 합니다.

끄면 기존처럼 사진 비율에 맞춰 프레임 전체 크기가 자동으로 줄어듭니다.

켜면 프레임은 오브젝트 전체를 채우고, 사진만 비율에 맞게 표시됩니다. 사진 비율과 프레임 비율이 맞지 않아 남는 공간은 `Margin Color`와 `Margin Texture`로 채워집니다.

### Set ratio

`Aspect ratio from texture`를 끈 경우 직접 사용할 비율입니다.

예시:

- 가로 16:9 사진: `16, 9`
- 정사각형: `1, 1`
- 세로 9:16 사진: `9, 16`

특정 크기의 포스터 프레임처럼 항상 같은 비율로 보이게 하고 싶을 때 사용합니다.
